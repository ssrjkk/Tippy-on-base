# GTM: оффер для Telegram-каналов (5 каналов до подачи гранта)

Цель: 5 реальных крипто-каналов, которые согласились монетизировать контент
через Tippy paywall. Это traction для формы Base Builder Grant.
Сейчас продукт готов (368 автотеста) и ждёт деплоя; оффер — на «ранний
доступ»: админ соглашается сейчас, активация через 1 день после деплоя.

## 1. Кого искать (по убыванию приоритета)

| # | Тип канала | Почему | Примеры ниш |
|---|---|---|---|
| 1 | Сигналы/торговля (3–30k подписчиков) | Платят за «закрытые сигналы» — самый очевидный use-case | `@crypto_signals_*`, «сигналы на Base» |
| 2 | Аналитика/дайджесты (5–50k) | Платные отчёты за 1–5 USDC — прямое попадание в paywall постов | обзоры рынка, ончейн-дайджесты |
| 3 | AI-агенты/боты (1–10k) | Понимают x402, сами захотят платить/принимать | каналы про агентов, API, автоматизацию |
| 4 | Мемы/сообщества Base (10k+) | Лёгкая монетизация донатов/постов, тест-кейс для гранта | `@base_*`, мем-каналы экосистемы |
| 5 | Каналы разработчиков Base | Партнёрство с экосистемой, репост у них = трафик | `@base_builders_*`, дев-дайджесты |

Правило: не больше 5-7 сообщений в день на все каналы, только после
деплоя — демо-ссылки. До деплоя отправляется только «предзапись» (п. 4).

## 2. Оффер админу (что говорим)

- Канал монетизируется без KYC, без своей инфраструктуры, без кошельков для подписчиков.
- Подписчик платит **USDC на Base** прямо из баланса бота: депозит → покупка → доступ. Всё в Telegram, 0 газа.
- **0% комиссии на 3 месяца** для первых 5 каналов (после — 1% на вывод / 2% на выигрыш, как у бота).
- Админ получает **USDC сразу на баланс** и выводит в любой момент на свой кошелёк Base.
- Деньги подписчиков **защищены публично**: `/api/solvency` показывает, что резервы на Base покрывают все балансы (Proof of Reserves через контракт TipBotVault).
- Агенты/боты тоже могут платить: `POST /api/x402/paywall` — это первое, что заинтересует админов AI-каналов.

Что нужно от админа (5 минут):
1. Добавить бота админом в канал (`@base_tipbot`).
2. В канале написать `/paywall channel 5` (5 USDC / 30 дней).
3. Опубликовать пост-анонс с текстом из п. 3.
4. Прислать нам username канала и число подписчиков (для таблицы гранта).

## 3. Пост-анонс для канала (отдаём админу готовым)

```
🔐 Доступ к каналу теперь платный — 5 USDC / 30 дней.

Оплата в USDC на Base прямо в Telegram, без кошельков и KYC:
1. @base_tipbot → /start → /deposit (QR или отправка USDC на адрес)
2. В канале или боту: /paywall subscribe @<username>

Деньги подписчиков защищены публично: solvency-отчёт
показывает резервы на Base против всех балансов.
Продавец и покупатель видят каждую операцию: /history.

Подписка управляется автоматически: доступ до даты,
продление в один тап, без забот.
```

## 5. Трекинг (таблица для гранта)

Файл `GTM_TRACKING.md` — по одному каналу на строку:

| Канал | Тип | Подписчики | Статус | Дата | Комиссия |
|---|---|---|---|---|---|
| `@example` | сигналы | 12k | предзапись принята | 2026-08-20 | 0% 3 мес |
| ... | | | | | |

Статусы: `контакт` → `предзапись принята` → `активен` (после деплоя) →
`первая продажа`. В форму гранта идут только каналы со статусом
`предзапись принята` и выше; числа подписчиков — честные.

## 6. Ответы на возражения

- «У меня уже платная подписка через Boosty/патрон» → у нас USDC на Base
  и доступ в один тап внутри Telegram; для крипто-аудитории это нативно.
- «Зачем подписчикам кошелёк?» → кошелёк не нужен: баланс в боте,
  депозит по QR-адресу. Это 1 минута.
- «А если ты убежишь с деньгами?» → адрес контракта и solvency публичны;
  любой может сверить балансы с резервами на Base (Proof of Reserves).
- «Мои подписчики не знают, что такое USDC» → анонс в п. 3 написан
  для людей без крипто-опыта; депозит = «как перевод на карту».
- «Что с налогами?» → выводишь USDC сам на свой кошелёк; это твоя
  ответственность, у нас нет KYC и нет выдачи фиата.

3. После первой продажи: обновить GTM_TRACKING.md, скриншот
