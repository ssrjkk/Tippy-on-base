# Tippy в экосистеме Coinbase/Base — стратегия позиционирования

Исследование: август 2026.

> **Решение по бренду (28.08.2026):** ончейн-слой прогнозных рынков называется **Cally** («call the outcome», фонетическая сестра Tippy). Базнейм `cally.base.eth` свободен и резервируется при деплое. Техническое имя контракта — OutcomeMarket (не меняется). Фокус — три кита продукта: **чаевые**, **Polymarket-слой**, **AI-агент**.

## Что строит Coinbase/Base (карта экосистемы)

| Слой | Продукт | Суть |
|---|---|---|
| Дистрибуция | **Base App** (бывш. Coinbase Wallet) | «everything app»: кошелёк + чат + соцлента + **mini apps** + платежи; онрампы (Apple Pay и др.), NFC |
| Дистрибуция | **MiniKit** | SDK mini-приложений для ленты Base App (одна кодовая база, gasless через Paymaster) |
| UI-компоненты | **OnchainKit** | React-компоненты: Identity (Basenames), Wallet, Swap, Checkout, Fund |
| Кошельки | **Smart Wallet / Base Accounts** | passkeys, Sub Accounts, **Spend Permissions** (делегирование трат агенту в пределах лимита), Paymaster (gasless) |
| Платежи | **USDC (native)**, Coinbase Business | стейблкоин-рельсы, приём платежей от агентов |
| Агентный стек | **AgentKit / Agentic Wallets / Payments MCP** | серверные кошельки для агентов (MPC + AWS Nitro), x402 в ядре; Payments MCP |
| Платежи агентов | **x402** (открытый протокол HTTP-402) | интеграция с Cloudflare, Google AP2/A2A; ~100M агентных платежей на Base |
| Идентичность | **Basenames** | имена вида name.base.eth |
| Гранты | **Base Build** | финансирование экосистемных команд |
| Прогнозные рынки | **Coinbase Predictions × Kalshi** | регулируемые event-контракты во всех 50 штатах США (запуск 28.01.2026), самый быстрорастущий продукт ($100M объёма), конкурирует с Polymarket/Kalshi. Внимание: расследование NY по рекламе прогнозных рынков |

## Наши три кита против их стека

### 1. Чаевые — идеально ложатся в Base App
- Telegram — наш канал №1, но Base App даёт **второй канал дистрибуции с тем же USDC**: mini app в соцленте = виральность, которой нет у ботов.
- Чаевые по Basenames (`/tip @name.base.eth`) вместо Telegram-ников.
- Gasless-чаевые через Paymaster — онбординг без ETH.

### 2. Polymarket-слой — наша ниша там, где Coinbase НЕ играет
- Coinbase Predictions = регулируемый CEX-продукт через Kalshi: ставки на спорт/политику, только США, **нельзя создать свой рынок**.
- Наша ниша: **комьюнити-рынки, создаваемые кем угодно, внутри чатов, микро-ставки, глобально, self-custody USDC**. Прямой конкуренции с Kalshi нет — мы про соцмеханику группы, они про трейдинг.
- Риск: регуляторное внимание к слову «prediction/betting» в США → в англоязычном UI держаться формулировок «community markets / social polls».

### 3. AI-агент — 우리 уже в их парадигме, надо говорить на их языке
- У нас своя реализация x402-хендшейка — **перейти на официальный протокол x402** (совместимость заголовков), чтобы Agentic Wallets / Payments MCP / любые x402-агенты платили нам из коробки.
- Зарегистрировать наши эндпоинты в x402-каталоге экосистемы.
- Агент продаёт сигналы/аналитику за USDC через x402 = ровно тот «agentic commerce», который Coinbase разгоняет.
- Следующий уровень: **Spend Permissions** — пользователь делегирует агенту бюджет, агент торгует на ончейн-рынках от его имени (их же примитив для агентных трат).

## Дорожная карта (приоритет)

1. **MiniKit mini app** — портировать дашборд/рынки/чаевые в Base App (OnchainKit Identity + Checkout + Fund). Это главный.unlock дистрибуции.
2. **Basenames** в_tip/профили + резолв в чаевых.
3. **x402-совместимость** с официальным протоколом + листинг.
4. **Gasless-чаевые** через CDP Paymaster.
5. **Spend Permissions** для агентной торговли (после того как смарт-аккаунты станут основным кошельком аудитории).
